Yaazhi for Linux

Yaazhi for Linux

Get Yaazhi for 64-bit Linux systems, with the Yaazhi Compiler, Yaazhi Runtime, Yaazhi Standard Library and examples.

Download Yaazhi SHA-256 Installation Guide

Direct archive: yaazhi-0.1.0-linux-x86_64.tar.gz · Version: Yaazhi 0.1.0 · Release notes

Install on Linux (for beginners)

1. Download the archive from the button above.
2. Open a terminal where the file was downloaded.
3. Run:

tar -xzf yaazhi-0.1.0-linux-x86_64.tar.gz
cd yaazhi-0.1.0
./install.sh

If you want to install for your user only, the installer supports a prefix such as ~/.local. After installing, make sure the install folder is on your PATH, then verify:

yaazhi --version

You should see:

Yaazhi 0.1.0

Verify your download

Compare the checksum of your file with the official SHA-256 value:

sha256sum yaazhi-0.1.0-linux-x86_64.tar.gz

Download the .sha256 file from the SHA-256 button and check that both values match. See the Releases page for the published checksum.

First run after install

# வணக்கம்.ழி
அச்சிடு($"வணக்கம், யாழி!")
yaazhi run வணக்கம்.ழி

Yaazhi for Windows

Yaazhi for Windows

Get Yaazhi for 64-bit Windows systems, with the Yaazhi Compiler, Yaazhi Runtime, Yaazhi Standard Library and examples.

Download Yaazhi Installation Guide

Version: Yaazhi 0.1.0 · Release notes

Install on Windows (for beginners)

1. Download the official Windows package from the button above and extract it.
2. Open PowerShell in the extracted folder.
3. Run the included installer:

powershell -ExecutionPolicy Bypass -File install.ps1

The installer copies Yaazhi into your user folder (no Administrator rights needed) and adds it to your user PATH. Then open a NEW terminal and verify your installation:

where.exe yaazhi
yaazhi --version

You should see:

Yaazhi 0.1.0

First run on Windows

yaazhi run வணக்கம்.ழி
