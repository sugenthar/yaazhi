Yaazhi 2D Game Library

Make 2D games in Tamil v1.0.0

The official Yaazhi 2D Game Library helps you build:

  • 2D games and characters
  • Movement and keyboard controls
  • Collision between things
  • Score systems
  • Game screens and game loops
  • Simple game projects like Coin Catch
