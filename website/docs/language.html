Yaazhi Language Reference

Yaazhi programs live in .ழி files. Blocks are written with indentation and begin with :. Notes start with #. Yaazhi is designed around Tamil — letters, names, words, sentences and numbers can all be Tamil.

எழுத்துக்கள் — Letters and files

Write Tamil directly. File names can also be Tamil, for example வணக்கம்.ழி.

அச்சிடு($"வணக்கம், யாழி!")

பெயர்கள் — Names (identifiers)

Use Tamil names for people, things and values:

பெயர் = $"யாழி"
வயது = $௧௮
ஊர் = $"மதுரை"

தமிழ் எண்கள் — Tamil numbers

Yaazhi supports Tamil numbers. Tamil digits:

௦ ௧ ௨ ௩ ௪ ௫ ௬ ௭ ௮ ௯

Numbers in programs start with $:

எண் = $௧௦
முடிவு = எண் + $௫
அச்சிடு(முடிவு)

$மெய் means true, $பொய் means false.

எழுத்துச்சரங்கள் — Strings (Tamil text)

வாழ்த்து = $"வணக்கம்"
பெயர் = $"அருள்"
அச்சிடு(வாழ்த்து + $" " + பெயர்)

மாறிகள் — Variables

பெயர் = $"யாழி"
வயது = $௧௮
அச்சிடு(பெயர்)
அச்சிடு(வயது)

செயல்கள் — Functions

செயல் creates a reusable action. கொடு gives back a value:

செயல் கூட்டு(அ, ஆ):
    கொடு அ + ஆ

முடிவு = கூட்டு($௧௦, $௨௦)
அச்சிடு(முடிவு)
செயல் வாழ்த்து(பெயர் = $"நண்பா"):
    அச்சிடு($"வணக்கம் " + பெயர்)

வாழ்த்து()
வாழ்த்து($"அருள்")

நிபந்தனைகள் — Conditions

என்றால் means “if”, இல்லை means “else”:

எண் = $௫
என்றால் எண் > $௩:
    அச்சிடு($"பெரிய எண்")
இல்லை:
    அச்சிடு($"சிறிய எண்")

சுழற்சிகள் — Loops

வரை repeats while something is true. ஒவ்வொரு … இல் visits each item. வரம்பு gives a range of Tamil numbers:

எண் = $௧
வரை எண் <= $௩:
    அச்சிடு(எண்)
    எண் = எண் + $௧
ஒவ்வொரு எண் இல் வரம்பு($௧, $௫):
    அச்சிடு(எண்)

பட்டியல்கள் — Lists

எண்கள் = [$௧, $௨, $௩]
அச்சிடு(எண்கள்[$௦])
ஒவ்வொரு எண் இல் எண்கள்:
    அச்சிடு(எண்)

அகராதிகள் — Dictionaries

மாணவர் = {"பெயர்": $"அருள்", "வயது": $௨௦}
அச்சிடு(மாணவர்["பெயர்"])
அச்சிடு(மாணவர்["வயது"])

வகுப்புகள் — Classes and objects

வகுப்பு describes a kind of thing. இது means “this one”. செயல் inside a class is a method:

வகுப்பு மாணவர்:
    செயல் உருவாக்கு(பெயர், வயது):
        இது.பெயர் = பெயர்
        இது.வயது = வயது

    செயல் வணக்கம்():
        அச்சிடு($"வணக்கம் " + இது.பெயர்)

ம = மாணவர்($"அருள்", $௨௦)
ம.வணக்கம்()

பிழை கையாளுதல் — Errors

முயற்சி tries, பிழை catches a problem, இறுதியில் always runs, எறி raises an error:

முயற்சி:
    முடிவு = $௧௦ / $௨
    அச்சிடு(முடிவு)
பிழை தவறு:
    அச்சிடு($"பிழை: " + தவறு)
இறுதியில்:
    அச்சிடு($"முடிந்தது")

தொகுதிகள் — Modules (reusing code)

சேர் brings library code into your program:

சேர் கணிதம்
சேர் தரவு
சேர் கோப்பு

அச்சிடு(கணிதம்.அடுக்கு($௨, $௩))

கோப்புகள் — Files

சேர் கோப்பு
கோப்பு.எழுது_மூலம்($"வணக்கம்.txt", $"வணக்கம், யாழி!")
உரை = கோப்பு.படி_மூலம்($"வணக்கம்.txt")
அச்சிடு(உரை)

JSON

சேர் தரவு
மாணவர் = {"பெயர்": $"அருள்", "வயது": $௨௦}
உரை = தரவு.ஜெசன்(மாணவர்)
அச்சிடு(உரை)

வலை — Web

சேர் வலை
# ஒரு சிறிய சேவையகத்தைத் தொடங்கு (முழு எடுத்துக்காட்டு: வலை பக்கம்)
சேவையகம் = வலை.சேவையகம்($௧௮௦௮௦)
அச்சிடு($"சேவையகம் தயார்")
