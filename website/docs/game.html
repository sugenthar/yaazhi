2D Game Development with Yaazhi

The Yaazhi 2D Game Library lets you make 2D games in Tamil: characters, movement, keyboard controls, collision, score systems, game screens and game loops.

Your first game — நாணயம் பிடி (Coin Catch)

சேர் விளையாட்டு
விளையாட்டு.சாளரம்($"நாணயம் பிடி", $௪௦, $௧௮)
செயல் ஆட்டச்_சட்டகம்():
    விசை = விளையாட்டு.விசை_படி($"நகர்: ")
    என்றால் விசை == $"வெளி":
        விளையாட்டு.நிறுத்து()
    விளையாட்டு.திரை_துடை()
    விளையாட்டு.எல்லை($"#")
    விளையாட்டு.காட்டு()
விளையாட்டு.இயக்கு(ஆட்டச்_சட்டகம்)

Run with yaazhi run விளையாட்டு.ழி.

What you can build

  • Characters that move with the keyboard
  • Shapes, screens and score displays
  • Collision — when two things touch
  • Game loops — pictures that keep updating
  • Small full games like Coin Catch

New project for a game

yaazhi new என்_விளையாட்டு
cd என்_விளையாட்டு
yaazhi run
