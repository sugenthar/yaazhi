Web · Files · JSON · Database

Yaazhi can build servers, web apps, file tools and data apps — all in Tamil.

Web server — வலை

சேர் வலை
சேவையகம் = வலை.சேவையகம்($௧௮௦௮௦)
அச்சிடு($"சேவையகம் தயார்")

Run with yaazhi run சேவையகம்.ழி, then open http://127.0.0.1:18080/ in your browser. Stop with Ctrl+C.

Web request — இணைய இணைப்பு

சேர் வலை
பதில் = வலை.பெறு($"http://127.0.0.1:18080/")
அச்சிடு(பதில்)

WebSocket

சேர் வலை
இணைப்பு = வலை.இணையச்சாளரம்($"ws://127.0.0.1:18082/")
இணைப்பு.அனுப்பு($"வணக்கம்!")
அச்சிடு(இணைப்பு.செய்தி())

JSON

சேர் தரவு
மாணவர் = {"பெயர்": $"அருள்", "வயது": $௨௦}
உரை = தரவு.ஜெசன்(மாணவர்)
அச்சிடு(உரை)

Files

சேர் கோப்பு
கோப்பு.எழுது_மூலம்($"நாள்.txt", $"வணக்கம், யாழி!")
உரை = கோப்பு.படி_மூலம்($"நாள்.txt")
அச்சிடு(உரை)

Database — தரவுத்தளம்

சேர் தரவுத்தளம்
தளம் = தரவுத்தளம்.இணை($":நினைவகம்:")
தளம்.இயக்கு($"CREATE TABLE மாணவர் (பெயர் TEXT, வயது INT)")
தளம்.இயக்கு($"INSERT INTO மாணவர் VALUES ('அருள்', 20)")
முடிவு = தளம்.தேடு($"SELECT * FROM மாணவர்")
அச்சிடு(முடிவு)
