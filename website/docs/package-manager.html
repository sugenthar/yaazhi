Yaazhi Package Manager

The Yaazhi Package Manager helps you create projects, add libraries, and share code. Projects use a yaazhi.toml file.

yaazhi new என்_திட்டம்
cd என்_திட்டம்
yaazhi run

Everyday commands

CommandSimple meaning
yaazhi initStart package setup in a folder.
yaazhi installAdd libraries to your project.
yaazhi removeRemove a library.
yaazhi updateUpdate libraries.
yaazhi listShow installed libraries.
yaazhi searchFind libraries.
yaazhi packPack your project for sharing.
yaazhi cleanClean build files.
yaazhi doctorCheck your setup.

Project file — yaazhi.toml

["திட்டம்"]
"பெயர்" = "என்_விளையாட்டு"
"பதிப்பு" = "1.0.0"
"நுழைவாயில்" = "src/முதன்மை.ழி"

["சார்புகள்"]
"விளையாட்டு_நூலகம்" = "1.0.0"
