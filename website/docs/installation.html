Installation — Yaazhi 0.1.0

Linux x86_64

Yaazhi is available for 64-bit Linux systems.

Download Yaazhi SHA-256 
tar -xzf yaazhi-0.1.0-linux-x86_64.tar.gz
cd yaazhi-0.1.0
./install.sh

Then verify:

yaazhi --version
yaazhi doctor

The bundle includes the Yaazhi Compiler, Yaazhi Runtime, Yaazhi Standard Library and examples.

Windows x86_64

Yaazhi is available for 64-bit Windows systems.

Download Yaazhi

Install step by step

1. Download the official Windows package from GitHub Releases and extract it.
2. Open PowerShell in the extracted folder.
3. Run the included installer (user-level install — no Administrator rights needed):

powershell -ExecutionPolicy Bypass -File install.ps1

The installer copies Yaazhi into your user folder and adds it to your user PATH. 4. Open a NEW terminal and verify your installation:

where.exe yaazhi
yaazhi --version

You should see:

Yaazhi 0.1.0

Then run your first program:

yaazhi run வணக்கம்.ழி
