Getting Started with Yaazhi

Yaazhi — யாழி is a Tamil-based programming language used to build games, servers, applications, AI/LLM projects, and other software. You write programs using Tamil letters, words, names, keywords and Tamil numbers. A Yaazhi source file ends with .ழி. This page takes you from zero to your first running program in a few minutes.

Learning path: தொடக்கம் → அடிப்படை → செயல்கள் → தரவுகள் → வகுப்புகள் → தொகுதிகள் → கோப்புகள் → JSON → வலை → தரவுத்தளம் → விளையாட்டுகள் → திட்டங்கள்

1. Install Yaazhi 0.1.0

New to Yaazhi? Download Yaazhi first, then follow your platform below.

Linux

tar -xzf yaazhi-0.1.0-linux-x86_64.tar.gz
cd yaazhi-0.1.0
./install.sh
yaazhi --version

Windows

Download the official Windows package from GitHub Releases, extract it, then run the included installer in PowerShell:

powershell -ExecutionPolicy Bypass -File install.ps1

Then open a NEW terminal and check:

yaazhi --version

macOS

macOS support is coming soon. Please use Linux or Windows for now.

2. First program — வணக்கம்

Create a file named வணக்கம்.ழி with this content:

அச்சிடு($"வணக்கம், யாழி!")

This prints:

வணக்கம், யாழி!

Run it:

yaazhi run வணக்கம்.ழி

அச்சிடு means “print”. .ழி is the Yaazhi source-file extension. yaazhi run compiles and runs your program using the Yaazhi Compiler and Yaazhi Runtime.

3. Tamil numbers

Yaazhi uses Tamil numbers:

௦ ௧ ௨ ௩ ௪ ௫ ௬ ௭ ௮ ௯
எண் = $௧௦
முடிவு = எண் + $௫
அச்சிடு(முடிவு)

Tamil digits begin with $: $௧௦ is ten, $௫ is five. Tamil identifiers like எண் and முடிவு are normal names in Yaazhi.

4. Variables — மாறிகள்

பெயர் = $"யாழி"
வயது = $௧௮
அச்சிடு(பெயர்)
அச்சிடு(வயது)

5. Check, build and interactive mode

yaazhi check வணக்கம்.ழி   # check without running
yaazhi build வணக்கம்.ழி   # build your program
yaazhi repl               # try Yaazhi interactively
yaazhi --help             # all commands
yaazhi doctor             # check your setup

6. New project

yaazhi new வணக்கம்
cd வணக்கம்
yaazhi run

This creates a ready project with a yaazhi.toml file and a starting .ழி program. The Yaazhi Package Manager handles project setup and libraries.

Yaazhi commands

CommandWhat it does (simple words)
yaazhi --versionShow your Yaazhi version (should be Yaazhi 0.1.0).
yaazhi --helpShow help for all commands.
yaazhi runRun a .ழி file or project.
yaazhi checkCheck a program without running it.
yaazhi buildBuild your program.
yaazhi replTry small Yaazhi lines interactively.
yaazhi newCreate a new Yaazhi project.
yaazhi doctorCheck that Yaazhi is set up correctly.

Package commands

CommandWhat it does
yaazhi initStart package setup in a folder.
yaazhi installAdd libraries to your project.
yaazhi removeRemove a library.
yaazhi updateUpdate libraries.
yaazhi listShow installed libraries.
yaazhi searchFind libraries.
yaazhi packPack your project for sharing.
yaazhi cleanClean build files.
