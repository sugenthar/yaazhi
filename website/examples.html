Yaazhi Examples — 21 lessons

Learn step by step, from your first word to games and web apps. Save each block as a .ழி file and run with yaazhi run <file>.ழி.

Start with simple Tamil programs and gradually build real applications, web projects, servers, and games.

Learning path: தொடக்கம் → அடிப்படை → செயல்கள் → தரவுகள் → வகுப்புகள் → தொகுதிகள் → கோப்புகள் → JSON → வலை → தரவுத்தளம் → விளையாட்டுகள் → திட்டங்கள்

அடிப்படைகள் — Basics

01 — வணக்கம் (First program)

அச்சிடு($"வணக்கம், யாழி!")

Run: yaazhi run வணக்கம்.ழி

10 — வகுப்புகள் (வகுப்பு / இது / செயல்)

வகுப்பு மாணவர்:
    செயல் உருவாக்கு(பெயர், வயது):
        இது.பெயர் = பெயர்
        இது.வயது = வயது

    செயல் வணக்கம்():
        அச்சிடு($"வணக்கம் " + இது.பெயர்)

ம = மாணவர்($"அருள்", $௨௦)
ம.வணக்கம்()

பொருட்கள் மற்றும் முறைகள்

வகுப்பு கணக்கு:
    செயல் உருவாக்கு(தொகை):
        இது.தொகை = தொகை

    செயல் சேர்(எண்):
        இது.தொகை = இது.தொகை + எண்
        கொடு இது.தொகை

க = கணக்கு($௧௦௦)
அச்சிடு(க.சேர்($௫௦))
