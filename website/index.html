What is Yaazhi?

Yaazhi is a programming language based on Tamil. It allows developers to write programs using Tamil letters, Tamil words, Tamil identifiers, Tamil keywords, Tamil numbers, Tamil strings and .ழி source files.

Yaazhi is designed to make programming possible through Tamil syntax while providing tools for creating real software — games, servers, web applications, AI/LLM projects, automation, data-oriented projects and learning projects. Anyone interested in Tamil can learn Yaazhi — no prior programming experience is needed.

Tamil programming

Yaazhi's syntax is designed around Tamil rather than simply translating a few keywords. Names, words, sentences and numbers can all be Tamil:

# வணக்கம்.ழி — a Yaazhi source file
பெயர் = $"யாழி"
வயது = $௧௮
அச்சிடு(பெயர்)
அச்சிடு(வயது)

Tamil numbers in Yaazhi

Yaazhi supports and uses Tamil numbers:

௦ ௧ ௨ ௩ ௪ ௫ ௬ ௭ ௮ ௯
எண் = $௧௦
முடிவு = எண் + $௫
அச்சிடு(முடிவு)

Tamil digits start with $, for example $௧௦ and $௫. Words like $மெய் and $பொய் express true and false.

First Yaazhi program

# வணக்கம்.ழி
அச்சிடு($"வணக்கம், யாழி!")

This prints:

வணக்கம், யாழி!

Run it with:

yaazhi run வணக்கம்.ழி

.ழி is the Yaazhi source-file extension. yaazhi run compiles and runs your program with the Yaazhi Compiler and Yaazhi Runtime.
