Yaazhi VS Code Extension — 0.1.0

Write Yaazhi comfortably in Visual Studio Code. The Yaazhi VS Code Extension works with .ழி files and the Yaazhi Compiler.

Features

  • Yaazhi syntax highlighting for Tamil code
  • IntelliSense suggestions for Yaazhi words
  • Diagnostics that show problems clearly
  • Run your program with one command
  • Build your program
  • Check your program without running
  • Yaazhi terminal with correct Tamil display
  • Yaazhi project support (yaazhi.toml)

Install

code --install-extension vscode-extension/yaazhi-language-0.1.0.vsix

Or in VS Code: Extensions view → … → Install from VSIX → choose the .vsix file.

Run, Build, Check

CommandWhat it does
Yaazhi: Run FileRuns the open .ழி file (yaazhi run).
Yaazhi: Run ProjectRuns the whole project from its yaazhi.toml.
Yaazhi: BuildBuilds the current file.
Yaazhi: CheckChecks the current file without running.

Tamil display tip

If Tamil looks broken in the terminal, use a Tamil-capable font in VS Code settings:

"terminal.integrated.fontFamily": "Nirmala UI, Noto Sans Tamil, Consolas"
