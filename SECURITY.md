# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.0   | Yes       |

## Reporting a vulnerability

Open a **private** report via GitHub Issues on the source repository
(<https://github.com/sugenthar/yaazhi-code/issues>) — do not post exploits
publicly. Include: version (`yaazhi --version`), OS/arch, reproduction steps,
and expected vs actual behaviour.

We will acknowledge receipt, investigate against the real compiler/runtime,
and publish a fix plus release notes. Do not include passwords, tokens, or
private data in reports.
