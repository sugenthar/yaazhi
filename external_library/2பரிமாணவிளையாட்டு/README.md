# 2பரிமாணவிளையாட்டு — யாழி 2D விளையாட்டுச் சட்டகம் (v1.0.0)

யாழி நிரல்மொழியின் முதல் அதிகாரப்பூர்வ வெளி விளையாட்டு நூலகம் —
நிலையான, சோதிக்கப்பட்ட **2D game framework**: தூய-யாழித் தருக்கம் +
முனையப் பின்விளைவு + உண்மை SDL3 இயல்புநிலைப் பின்தளம்
(`native/build/y2d_backend` — VERIFIED BY EXECUTION).

```text
யாழி விளையாட்டு (project-game — முனையம் + இயல்புநிலை முறைகள்)
      ↓ சேர் (கோப்பு இறக்குமதி + மாற்றுப்பெயர்)
2பரிமாணவிளையாட்டு — தமிழ் பொது API (src/மையம்.ழி, 31 தொகுதிகள்)
      ↓ பின்தளச் சுருக்கம் (சாளரம்/உள்ளீடு/ஒலி/படம் + பின்தளம் இயக்கி)
      ├─→ முனையப் பின்தளம் — TERMINAL FALLBACK VERIFIED
      └─→ y2d_backend (SDL3) — VERIFIED BY EXECUTION (Linux x86_64)
```

  (`yaazhi.toml`, `src/` (31), `assets/`, `examples/` (17),
  `tests/`, `native/` (மூலம் + vendor + build))
- சார்பு: உள்ளூர் பாதை (`["சார்புகள்"] "2பரிமாணவிளையாட்டு" =

## விளையாட்டை உருவாக்குதல்

முனையம் (இயல்பு) அல்லது இயல்புநிலை (`YAAZHI_BACKEND=<துறை>`
சூழல் மாறி + இயங்கும் `y2d_backend`):

```yaazhi
விளையாட்டு.சாளரம்("என் விளையாட்டு", $௪௦, $௧௮)

    விசை = விளையாட்டு.விசை_படி("நகர்: ")
    என்றால் விசை == "வெளி":
        விளையாட்டு.நிறுத்து()
    விளையாட்டு.திரை_துடை()
    விளையாட்டு.எல்லை("#")
    விளையாட்டு.காட்டு()
விளையாட்டு.இயக்கு(ஆட்டச்_சட்டகம்)
```

இயல்புநிலை: `native/build.sh` → `native/build/y2d_backend --serve`
→ `YAAZHI_BACKEND=47832 yaazhi run .` (project-game இரு முறைகளையும் காட்டும்).
