# native/ — பின்தளக் குறிப்பு + பால விவரக்குறிப்பு (v0.3.0)

v0.3.0-இல் இயங்கும் இயந்திரக் (native) குறியீடு **தேவையில்லை**: நூலகம்
முழுவதும் தூய யாழி (`src/*.ழி`), பின்தளம் முனையம் (ANSI escape —
`அச்சிடு` வழியே). இக்கோப்பகம் வேண்டுமென்றே குறியீடு இல்லாமல்
ஆவணம் மட்டும் கொண்டுள்ளது — போலி/சோதிக்காத C குறியீட்டைத் தவிர்க்க.
இங்கு SDL2/raylib சார்பு எதுவும் சேர்க்கப்படவில்லை (கட்டவோ
சோதிக்கவோ முடியாததைச் சேர்ப்பதில்லை).

## ஏன் தூய யாழி

யாழி இயங்குநிலையில் பயனர்-FFI இல்லை (`runtime/ffi` = PLANNED), மற்றும்
தொகுப்பி பகுப்பாய்வி அறிந்த native பெயர்களுக்கு வெளியே எந்த அழைப்பையும்
(`வரையறுக்கப்படாத செயல்`) நிராகரிக்கும். எனவே புது natives-ஐ
இயங்குநிலையில் பதியாமல் (களஞ்சியத்துக்கு வெளியே மாற்றம் தடை)
அடைய முடியாது. தற்போதுள்ள natives மட்டும் போதும்: `அச்சிடு` (ANSI),
`பெறு` (வரி உள்ளீடு), `இப்போது`/`உறக்கம்` (நேரம்),
`நிரல்_கோப்பு_*` (படக் கோப்புகள்), `நிரல்_சீரற்ற_*`,
`பகுப்பாய்வு` (`\u001b`/`\u0007` உருவாக்கம்), `பிழையிடு`.

## கட்டமைப்பு (தற்போது)

```text
யாழி விளையாட்டு (project-game/src/main.ழி)
      ↓ சேர் (கோப்பு இறக்குமதி + மாற்றுப்பெயர்)
2பரிமாணவிளையாட்டு (src/*.ழி — பொது API: src/மையம்.ழி)
      ↓ வரைதல்/உள்ளீடு/ஒலிச் சுருக்கம் (சாளரம்/உள்ளீடு/ஒலி தொகுதிகள்)
முனையப் பின்தளம் (ANSI வரைதல் / வரி உள்ளீடு / மணி) → இயங்குதளம்
```

## எதிர்கால இயங்குநிலைப் பாலம் (விவரக்குறிப்பு — குறியீடு இல்லை)

FFI + பகுப்பாய்வி அட்டவணை விரிவாக்கம் வந்ததும், பொது API
(`விளையாட்டு.*`) மாறாமல் கீழ்க்கண்ட பாலச் செயல்களை (`நிரல்_விளை_*`
பெயர்வெளியில்) பதிவு செய்யலாம். `src/சாளரம்.ழி`, `src/உள்ளீடு.ழி`,
`src/ஒலி.ழி` ஆகிய மூன்று சுருக்கத் தொகுதிகள் மட்டுமே இவற்றை
அழைக்கும் — மற்ற 13 தொகுதிகள் (கணிதம், நிலை, சொத்து…) மாறாது:

## பாலச் செயலாக்க நிலை (v1.0.0 — செயல்படுத்தப்பட்டது ✓ / எதிர்காலம் ○)

சாளரம் ✓ (திற/தலைப்பு/அளவு/குறைந்தளவு/முழுத்திரை/மறை/காட்டு/
சிறிதாக்கு/பெரிதாக்கு/மீட்டமை/தகவல்/காட்சி/ஒத்திசை) · வரைதல் ✓
(துடை/செவ்வகம்/வட்டம்/கோடு/முக்கோணம்-நிரப்பல்/கலப்பு/வெட்டு/
காட்சிப்பகுதி) · இழைமம் ✓ (ஏற்று/PNG/JPG/BMP/வரை/விரிவு-சுழற்சி/
மூலம்/நீக்கு/எண்) · விசை ✓ (அழுத்தம்/விடுப்பு/மீள்வு/உரை) ·
சுட்டி ✓ (நிலை/பொத்தான்/சக்கரம்/தெரிவு/நகர்த்தல்) ·
கட்டுப்படுத்தி ◐ (எண்ணிக்கை/நிகழ்வுப் பாதை; வன்பொருள் இல்லை) ·
ஒலி ✓ (WAV/OGG ஏற்று/இயக்கு/சுழல்/இசை/ஒலியளவு/முடக்கு/எண்;
MP3 ○) · எழுத்து ✓ (தமிழ் வடிவமைப்பு உட்பட) · நேரம் ✓
(இயங்குநிலை டெல்டா யாழிப் பக்கம்; காட்சி ஒத்திசை) · கோப்பு ✓
(தற்போதுள்ள natives) · படப்பிடிப்பு ✓ (BMP) · சோதனைச் செலுத்தல் ✓
(INJECT — சோதனை-நோக்கு மட்டும்).

பின்தள விருப்பங்கள் (பாலம் பின்தள-சார்பற்றது): SDL2 · raylib ·
இணையான குறுக்குத் தள நூலகம். தள இலக்கு: Linux (சோதனை),
Windows, macOS (வடிவமைப்பு — செயலாக்கம் இல்லை).

பின்தளம்: SDL2 / raylib / இணையானது → OS வரைகலை/ஒலி/உள்ளீடு.
அதுவரை ஆதரிக்கப்படாதவை (நூலக README "அறியப்பட்ட வரம்புகள்"):
PNG/இருமப் படம், சுட்டி, கோப்பு ஒலி/இசை, எழுத்துரு, சுழற்சி,
பெரிதாக்கம், உண்மை முழுத்திரை, தடுக்கா விசை.
