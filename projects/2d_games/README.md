# project-game — நாணயம் பிடி (v1.0.0, 2பரிமாணவிளையாட்டு சோதனை விளையாட்டு)

`2பரிமாணவிளையாட்டு` நூலகத்தை வெளிச் சார்பாக நுகரும் உண்மை யாழித் திட்டம்.
நூலக மூலத்தை நகலெடுக்காது — `yaazhi.toml` சார்பு + இறக்குமதி வழியே பயன்படுத்தும்.

## அமைப்பு

```toml
["சார்புகள்"]
"2பரிமாணவிளையாட்டு" = "../2பரிமாணவிளையாட்டு"
```

`src/main.ழி` நூலகத்தை இறக்குமதி செய்யும் (`சேர் ... என விளையாட்டு`;
நேரடி `சேர் 2பரிமாணவிளையாட்டு` வடிவின் தொகுப்பி வரம்பு குறித்து
நூலக README.md "அறியப்பட்ட வரம்புகள்" பார்க்க).

## விளையாட்டு

**நாணயம் பிடி:** வீரன் இடது/வலது நகரும் (`அ`/`ஆ`), நாணயம் மேலிருந்து
விழும். பிடித்தால் மதிப்பெண் + மணி ஒலி; தவறினால் வாய்ப்புக் குறையும்;
3 தவறு = ஆட்டம் முடிவு. `வெளி` = வெளியேறு. முடிவில் மீண்டும் விளையாடும்
வாய்ப்பு. v1.0.0: பொருள் (entity) அடிப்படை, செயல்-வரைபட இயக்கம்,
மினுக்கும் நாணய அசைவு, பிடிப்புத் துகள், உயிர், கடின அதிகரிப்பு,
டெல்டா HUD, `best.txt` சிறந்த-மதிப்பெண் சேமிப்பு, **இயல்புநிலை
முறை** (`YAAZHI_BACKEND=<துறை>` + இயங்கும் `y2d_backend`):
உண்மைச் சாளரம், நேரடி விசை (a/d/அம்பு/escape), PNG-அல்லா வடிவ
வரைதல், தமிழ் HUD, மூடல் நிகழ்வு.
பயன்படுத்துவது: சாளரம், சுழற்சி, படம், அசைவு, துகள், பொருள்,
கட்டுப்பாடு, விசை, மோதல், நேரம் (டெல்டா), ஒலி, சேமிப்பு,
சீரற்ற விதை (உறுதியான நாணய வரிசை), பின்தளம் இயக்கி.

## இயக்கம்

```sh
yaazhi run .
```

ஒவ்வொரு சட்டகமும் ஒரு விசை வரியை எதிர்பார்க்கும் (முனைய வரி-உள்ளீடு).
தானியங்குச் சோதனை: `../2பரிமாணவிளையாட்டு/tests/run_tests.sh`
(`game-catch`, `game-over` காட்சிகள்).
